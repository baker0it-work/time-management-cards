# Управление временем

Интерактивный статический сайт с деревом тем по тайм-менеджменту.

## Содержание

- интерактивная главная страница;
- 14 подробных страниц карточек;
- исходный текст каждой карточки;
- расширенный разбор темы;
- 10 практических примеров для каждой карточки;
- последовательные шаги изучения.

## Запуск

Сайт не требует сборки или установки зависимостей. Откройте `index.html` в браузере или запустите любой статический HTTP-сервер из корня репозитория.

## GitHub Pages

Для публикации через GitHub Pages выберите ветку `main` и каталог `/ (root)` в настройках Pages репозитория.
